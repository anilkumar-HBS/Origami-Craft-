# 🦢 Origami Craft

**Origami Craft** is a creative web project dedicated to the beautiful art of paper folding. The website provides users with an engaging and simple way to explore origami crafts, discover different designs, and learn how to create paper art.

## ✨ Features

* 🎨 Beautiful and creative origami-themed design
* 📄 Collection of different origami crafts
* 📖 Easy-to-follow instructions
* 🖼️ Craft images and visual guides
* 📱 Responsive design for mobile, tablet, and desktop
* 🚀 Simple and user-friendly interface

## 🛠️ Technologies Used

* **HTML5** — Website structure
* **CSS3** — Styling and responsive design
* **JavaScript** — Interactive functionality

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/origami-craft.git
```

### 2. Open the project

Navigate to the project folder:

```bash
cd origami-craft
```

### 3. Run the website

Open `index.html` in your browser.

For the best development experience, you can use **Live Server** in VS Code.

## 🎯 Purpose

The main goal of Origami Craft is to make paper folding fun, creative, and accessible to everyone. Whether you are a beginner or an origami enthusiast, the website can help you explore new paper crafts.
